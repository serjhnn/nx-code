# nx-code

A coding agent built from scratch — by me, for me.

## About

nx-code is a personal project to build my own AI coding agent. Instead of only using existing tools, the goal is to understand how coding agents work under the hood by designing and implementing one myself: reading and editing code, running commands, and working through programming tasks step by step.
